# ASI-Bench 0.3.0

This release includes framework features and scoring fixes since 0.2.0.

- Add Harbor verification, single-task and batch export, and score aggregation
  for materialized public seed31415 instances. Reuse local scoring's isolated
  input staging and task runtimes, and remove stale rewards on evaluator errors.
- Support explicit MCP deployments in OS sandboxes, including instance stdio
  and runtime-service HTTP deployments, with protocol preflight and cleanup.
  Configure MCP independently from web search. Support explicit Codex tool
  timeouts for long scientific calls.
- Fix BenchFlow scoring to stage original instance data alongside persisted
  model outputs, matching standard local scoring. Reuse task-runtime preparation
  and report evaluator failures as invalid evaluations with `score: null`.
  Consumers must exclude invalid evaluations from score aggregates.
- Expand repository scientific MCP integrations and validation resources for
  materials workflows, FEniCSx/Gmsh, ASE/OVITO and LAMMPS, and add a task-authoring
  guide. These integrations, Docker definitions, tasks and examples remain
  repository resources; the PyPI distributions contain the framework package
  and package metadata. External software and images are installed separately.

Upgrade:

```bash
pip install --upgrade 'asibench==0.3.0'
# Optional model and scientific dependencies:
pip install --upgrade 'asibench[full]==0.3.0'
```

Python 3.11 or later is required. Both `asibench` and the compatibility command
`ai4sci-bench` remain available. seed31415 local scoring remains non-official;
seed42 references remain private and are not distributed in the package.
