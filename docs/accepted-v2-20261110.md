# Accepted v2 task intake (2026-11-10)

This change prepares 15 accepted tasks for the public scoring catalog. The existing
60-task results and Hugging Face datasets have not been extended by this commit.
The proposed catalog has 75 formal definitions; the new seed31415 payload must be
published separately before these additions can be pulled from the hosted dataset.

Formal task directories contain only `task_meta.yaml`, scoring-only
`task_eval.yaml`, `custom_scorer.py`, and exact evaluator helpers declared in
`config/public_scorers.json`. Prompt templates and GT generators are excluded.
The prompt filenames in metadata refer to the materialized instance bundle.

The retry-storm simulator and Maxwell numerical evaluation kernel are evaluator
helpers named `retry_storm_eval_runtime.py` and `maxwell_eval_runtime.py`. Neither
builds instances or reference bundles. Agent runtime files use their existing
separate allowlist; evaluator helpers are not agent runtime declarations.

The option-surface scorer previously generated a replay at scoring time. Its
65-point replay component now reads `reference/replay/replay_1/{data,reference}`,
runs the same submitted program on that pre-materialized data, and applies the
original metrics, thresholds, and weights. The replay material is generated
privately using the original configured seed, 314159. Missing replay material is
an evaluator failure. The public scorer does not accept a seed or load a GT
generator. The original authoring version is retained in the source archive.

The grain-boundary task retains its declared LAMMPS MCP service requirement.
`asibench-lammps:test` is a local image tag, so executing agents for this task
requires building/provisioning the declared service image and MCP configuration.
Instance generation copies the measured reference assets and does not run LAMMPS.

Validation covers formal publication policy, loading all 15 task/scorer bundles,
and the materialized option replay boundary. It does not certify B1–B4 difficulty
or a complete agent/scorer run for every new task.
